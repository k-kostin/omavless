## Remaining release boundary

This closes the selected T2 client MVP, not every application feature or host
track. Import/edit/routing management remains in the plugin; persistent TUI
preferences, full connection tables, raw logs and graphical UI are outside T2.
Connected-network negative probe results remain visible evidence for the scoped
DNS/network/measurement follow-ups (#270–272), not failures silently changed to
PASS. AUTO-1, V0, P4, K1 and NixOS retain their separate gates.

Public 0.9.0 packages/pins, release metadata and marketplace promotion have not
been produced. The final release candidate needs its packaging/pairing and
release checks, explicit main-update authorization, and separately applicable
publication approval. Do not repeat unchanged T2/R6 manual gates merely because
this acceptance summary or the RC ledger gains a documentation commit.
