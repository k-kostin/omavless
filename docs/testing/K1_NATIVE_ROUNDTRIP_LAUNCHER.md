# K1: explicit current-owner roundtrip launcher

This is a development-only ignored test, not a daemon factory, a new IPC
method, an installed feature switch or an accepted coverage issuer. It is built
only with the existing protected native scenario. The ordinary product route
and `issue_coverage` remain unchanged; the latter still returns Unsupported.

The exact selector is
`production_owner::protected_native::native_vm_tests::installed_current_owner_protected_roundtrip`.
It refuses anything except UID/eUID/GID/eGID 1000, the disposable VM's real
`/home/kdk_vm`, `/run/user/1000`, explicit `OMAVLESS_NATIVE_K1_VM=1`, and no
alternative HOME, core or XDG roots. The sole profile is the separately
provisioned public synthetic `k1-native-fixed`; no credential is accepted in an
argument or printed by this launcher.

## Same originals, not reconstructed acceptance

Before the first normal constructor, an outer custody guard is installed.
It reads the current private desired snapshot without creating or repairing it
and requires Off with no selected profile. It refuses a preexisting control
socket rather than asking the ordinary bind to remove an unexplained object.
It then binds the actual singleton and constructs
`ProductionNativeOwner::current` with the real committed marker, current manager
receipt, installed pair, migration lease and startup reconciliation. This
constructor can have its ordinary startup effects; the supervisor must admit
the actual fixture and inactive service beforehand. It is not a read-only
constructor claim or a substitute for a real login preparation.

The actual owner must be Disconnected and the desired snapshot unchanged.
The whole reported pair moves directly to the existing consuming guarded
roundtrip: validation, Arm, connect, actual fixed traffic interval, explicit
disconnect, original stop/empty proof, Disarm and final Status. No bare executor,
fake host, replacement owner, copied receipt, separate binder or imported
matrix boolean substitutes for those originals. The outer transfer restores
even an internal partial-construction prefix to custody before returning Err.

Only a positively completed roundtrip returning Disconnected may retire
normally and emit `K1_NATIVE_CURRENT_OWNER_ROUNDTRIP_CLOSED`. A refusal or unwind
emits a closed phase category and parks; it cannot authorize a retry, status
adoption, guessed cleanup, child reaping or recovery. This guard retains the
resources constructors actually reported, not arbitrary unreported backend
descriptors, and cannot survive a fatal loss of its process.

is authorized by this development source.
