## Reproduced integration defects and corrections

The typed historical batch entry originally bypassed the shared early close
invalidation on proof refusal. Two actual-owner regressions use genuine opaque
evidence from another owner, not a Boolean permit or invented witness. Before
correction, stalled-close cancellation failed; an independent invocation retained
the old captured confirmation. Mutex poisoning in the initial combined negative
run is not counted as independent capture proof.

The shared entry now revokes unknown-operation capture/workers before typed proof
admission. Known operation IDs preserve a newer unrelated confirmation. Exact
job identity is checked before completion invalidation. Real terminal empty-job
registration and both refusal cases pass without permitting a store/core effect.

Three additional real-owner identity cases cover independently bound contexts
with colliding textual instance IDs, first tokens and revision zero:

1. A valid job from owner A cannot complete using owner B's genuine context.
   The pre-fix counterexample wrongly advanced A's registry and poisoned B.
   Early retained-Arc validation now returns `OwnershipUnavailable` before
   registry advancement, invalidation, cleanup or context poisoning.
2. Existing abort-ticket context identity rejects the same substitution.
   Removing only that guard reproduces the counterexample; restoring it passes.
3. A foreign context cannot be poisoned by preparing work on another owner.
   Before correction, the original prepared job subsequently failed recovery.
   Early Arc validation preserves that original context and job; their later
   genuine completion succeeds without recapture or rebase.

Own-context source drift still poisons and latches conservatively. An authentic
supervisor ticket can perform existing cleanup, not rehabilitate proof authority.
These alternatives remain test-only research. Independent read-only reviews
covered the corrected retained identity, lease/publication order and poisoning
boundaries; review alone is not execution evidence.
