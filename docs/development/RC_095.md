selected release candidate; it is a public validation prerelease, not stable

## Selected scope

`rc/0.9.5` starts from beta merge
`2dda2d8ef60dffcbf4bed524002ebaa2fd4626cf`. It retains accepted T2,
managed-DNS, probe/diagnostic semantics and native V0 disposition from
[RC 0.9.0](RC_090.md), then adds:

- #388: reviewed T3 chain through #372: page-local rules/providers, private
  connections, route inspection, volatile traffic/activity, fixed log-category
  hints and local host facts. Terminal teardown correction preserves the owner.
- #389: explicit `u` provider-information read for the selected TUI subscription.
  Claims are private, transient and provider-attributed; no background refresh,
  quota persistence or VPN-health inference.
- #390: beta artifact/version support; #392: installed x86_64 evidence,
  short socket fixtures and nonempty stale-row regression.
- RC1 metadata maps to Arch `0.9.5rc1-1`. Only the fourteen local crate versions
  change in Cargo.lock; no dependency, lifecycle or QML-layout change.

The [beta ledger](BETA_095.md) retains selection/integration history.

## Deliberately outside this RC

Unmerged branches are retained, not represented as enabled features:

- K1 observer/mark/firewall/receipt/enrollment foundations: no complete shipped
  protection owner/effect path; **no kill-switch claim**.
- S1 manager/lease/quiescence/dconf foundations: no admitted production takeover.
- T4 automatic refresh, persistent quota, recovery and authenticated backup:
  admission/storage/effect integration remains separate from explicit reads.
- T3 connection closing needs effect-time core identity guarantees. Additional
  history/activity/log refinements and #409/#411/#420 QML polish need separate
  combined acceptance; they are not silently added at scope freeze.
- P4 structured WG/AWG imports and G1 synthetic desktop comparison are not
  enabled product support.

#270/#132 remain open for stable 0.8.2; the mandatory managed-pair disposition
is accepted in the candidate, not reopened by unchanged T3/T4 code. #30 remains
Draft with preserved XHTTP evidence and unavailable-family gaps.
Default startup Off is unchanged; AUTO-1 remains deferred.

2026-10-01. The public-download and clean guided ARM64 gates below close the

notes/install instructions and limitations. Marketplace publication needs its
