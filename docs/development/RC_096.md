# 0.9.6 release-candidate ledger

Scope freeze proposed on 2026-10-01. The owner requested replacing the selected
0.9.5 candidate with 0.9.6. This `rc/0.9.6` branch starts from the reviewed
`beta/0.9.6` merge `7b82f5763343606bfc976d6561b985973e5384da`.

candidate is **RC-integrated, not yet an accepted or published RC**.

[#403](https://github.com/k-kostin/omavless/pull/403),

backup/quota integration, P4 protocol activation, G1 desktop application or
new V0 protocol claim is selected. AUTO-1 remains deferred. Open DNS/provider
and protocol maturity gaps retain their earlier disposition.

## Existing evidence and remaining gates

Combined deterministic tests, Rust parity, packaging CI and EN/RU synthetic
QML/TUI review passed on the exact beta heads listed in [the beta
ledger](BETA_096.md). The matching unpublished 0.9.6 beta app/DNS/frontend
pair passed installed ARM64 and [x86_64](../testing/BETA_096_PC_VM_2026-10-01.md)
bounded read-only reviews. The x86_64 review preserved private data and finished
Disconnected/Rule without a VPN transition. Unchanged 0.9.5 DNS/lifecycle
acceptance remains historical evidence, not a new 0.9.6 live-network pass.

The RC1 metadata does **not** inherit 0.9.5 hashes. Both committed package pins
remain empty until newly built `0.9.6rc1-1` app and production-DNS archives
are strictly inspected and matched to the exact RC frontend. Before calling
this a replacement *accepted* RC, complete exact-head CI, both-architecture
artifact inspection, affected installed update/read-side review, publication
of immutable RC assets with committed matching pins, anonymous download
verification and a clean guided first-use check. Record any actual failures and
limitations here, rather than relabeling beta evidence.

The existing [public 0.9.5 RC1](RC_095.md#public-rc1-acceptance) remains an
immutable, accepted historical candidate throughout this process. Stable main,
the 0.8.2 release and Marketplace are unchanged. Creating an RC branch is not
authorization to tag, publish packages, update main or request Marketplace
verification; those actions need their separate owner decisions.
