# 0.9.8 internal release-candidate ledger

Scope freeze prepared 2026-10-08 at the owner's request to consolidate beta.4,
ready cuts and PR disposition. This is **not accepted/public RC, main merge,
release/tag/assets or Marketplace authorization**. Source version is
`0.9.8-rc.1` / Arch `0.9.8rc1-1`; both bootstrap package maps remain empty.
Published 0.9.5 RC1, historical 0.9.6/0.9.7 candidates and stable main 0.8.2
retain their original identities and outcomes.

- The beta.4 normal-entry Backup and authenticated Preview/Cancel/Restore
  composition, including #701/#705/#708/#710 and the closed producer selection.
  Ordinary **Open app / `omavless tui`** exposes the included controls. Scope is
  profiles/subscriptions and finite supported routing template, not all settings
  or OS state; imported autoconnect remains Off. The earlier dedicated developer
  launcher is historical evidence, not the user entry.
- Guarded explicit application start after shutdown, #712
  `3f68ddfcb5a16fab081873869db568d133aa6a89`, corrected by #714:
  `19219d9ce6e4ee15cb9430ff5215ca1a0f12a8ed` binds readiness to the real
  Hello/status/Hello wire shape, authenticated fixed-unit peers and one deadline;
  `e598b4a095ce8771f0ad760fc4e68404ce4690cd` preserves broker-first setup when
  both services are stopped; `e4404bac936d4f06521ee59fc3939951bfc1f175` reports
  prepared components without claiming a still-stopped application is ready.
  No automatic Connect, unit enablement, preference
  reset, receipt invention, uncertain launch retry or Python fallback.
- #713 `31b9136b36c0a78a5a3a44cdf13c605e727c677d`: lossless ARM64/x86_64
  link-count normalization at seven file-identity comparisons. Every original
  ownership predicate remains; native package builds pass on both architectures.
- Existing maintenance/read-side UI changes, actual-entry regression and curated
  VM preflight/retrospective procedure. Current beta/main authorization rules
  are preserved; the older workflow branch is not imported wholesale.

The exact RC producer selects `t4-manager-actor-service` for this version only;
it does not select Product image-witness/connection-close or arbitrary future
versions. The regression follows actual Cargo metadata so a later version bump
cannot silently hide an included client again.

## Excluded scope

Product K1/kill switch, S1/App proxy, automatic subscription maintenance and
OS sleep/network recovery, WG/AWG P4 and GUI remain frontier work. Selective
connection-close activation needs its distinct qualified bundle/acceptance and
is not inferred from dormant inherited modules. V0/AUTO-1/deferred DNS/provider
requirements retain their current dispositions. This freeze closes no whole
T3/T4/K1 roadmap track and does not accept independent stopped-runtime Abort CLI
or legacy receiver experiments.
