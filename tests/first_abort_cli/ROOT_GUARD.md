## Ownership and terminal failure

Root starts under fixed trusted `setpriv --no-new-privs`; native credential
arguments drop each helper to UID/GID48044 with empty groups. The unchanged
helper proves all four UID/GID slots, P/I/E/A capabilities zero, NNP and original
namespace/ELF descriptors before effects. It execs the actual normal CLI in
the same owned PID. Only fixed read-only extra FDs198/199 are inherited; private
archive/passphrase input is stdin, never an argument or public log.

Direct raw WNOWAIT and one exact matching waitpid retain process ownership.
There is no Popen poll, cleanup supervisor, kill, timeout signal or retry.
Any uncertainty, failed child, malformed receipt or preservation failure
terminates before later reads/queries/effects. Known getent absence and pgrep
no-match are the only explicitly allowed nonzero query results. Their status
is not interpreted as a mutation's success.

There is one checked 600-second deadline, at most128 direct children, 8MiB per
captured output and 64MiB aggregate completed outputs. Retained lineage is
bounded to128MiB aggregate, not64MiB times an unbounded member count. Deadlines
are checked boundaries, not kernel I/O cancellation. Unknown children and
their artifacts are retained, not cleaned to satisfy a deadline.

Lineage pins original archive/request, ownership/desired, staged OLD/NEW/ready,
Intent, owner lock and mixed live predecessors before the first CLI call.
After exact known successful CLI and verification, the explicit first-Abort
transition adopts its OLD live pair and terminal once. Original immutable
members and predecessor descriptors remain held. Re-entry may not recapture
same-byte replacement inodes. The private receipts expose original identities
and hashes, not raw profiles. Point-in-time inode absence is not atomic
descendant absence, reboot/power-loss durability or full product acceptance.

reviewed receipt SHA, fixed nine-member source directory and create-only root
destination. It admits every original source FD, metadata/hash and ancestry
