# Source and contributions

This branch contains the stable user distribution. The complete source,
tests, build tools and developer instructions for this snapshot are preserved
at [the matching source commit](https://github.com/k-kostin/omavless/blob/1eda21ab2b4d9574200e7775f5ec9d256c6cd675).

For development, use a separate checkout of the full-source development branch
and read its AGENTS.md. Do not modify an installed user's plugin as a development
checkout. The moving development branch is not a substitute for a release's
immutable source provenance.

For installation or troubleshooting, use the [user guide](docs/user/NATIVE_INSTALL.md).
For agent-assisted bug reports and fixes, follow
[Report a bug or contribute a fix](docs/user/USER_AGENT_GUIDE.md#report-a-bug-or-contribute-a-fix).
